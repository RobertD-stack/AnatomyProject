The NetworkManager is a convenience class for the HLAPI for managing networking systems. For simple network applications the NetworkManager can be used to control the HLAPI.It provides simple ways to start and stop client and servers, to manage scenes, and has virtual functions that user code can use to implement handlers for network events. Detailed Description

The NetworkManager is a convenience class for the HLAPI for managing networking systems. For simple network applications the NetworkManager can be used to control the HLAPI.It provides simple ways to start and stop client and servers, to manage scenes, and has virtual functions that user code can use to implement handlers for network events.
